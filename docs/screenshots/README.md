# Screenshots

This directory holds screenshots used in the project README.

## How to Capture

1. Start the app locally: `npm run dev` from the repo root.
2. Open the browser at http://localhost:5173.
3. Capture the following pages at a viewport of ~1280x800:

| File | Page |
| --- | --- |
| `dashboard.png` | Dashboard (`/`) — shows KPIs, trend charts, and the hero metric |
| `defect-detail-ai-analysis.png` | Any defect detail page after running AI analysis (`/defects/:id`) |
| `create-defect.png` | Create Defect form (`/defects/new`) |

4. Save the screenshots into this directory (`docs/screenshots/`).
5. Commit them; the README references these paths with relative image links.

> Tip: Use browser DevTools device toolbar or a screenshot tool like Greenshot/ShareX to get consistent dimensions.
