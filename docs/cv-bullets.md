# DefectLens CV Bullets

## Portfolio Project

- Built DefectLens, an AI-assisted defect prevention tracker using React, Node.js, Express, Prisma, and SQLite to classify defect root causes, generate missing UAT scenarios, and produce CAB-ready release summaries.
- Created a full-stack MVP with seeded enterprise-style fictional defects, dashboard metrics, defect creation, AI/mock analysis, and release-governance summary generation.

## Technical BA

- Designed a shift-left defect prevention workflow connecting defect triage, root-cause analysis, test-coverage gaps, release risk, and preventive delivery actions.
- Modelled defect evidence into structured acceptance criteria, missing UAT scenarios, and practical prevention checklists.

## Technical PM

- Built dashboard views for analysis coverage, root-cause mix, high-risk modules, severity distribution, and recent release risks.
- Translated defect data into CAB-ready summaries to support release decisions, rollback planning, and delivery governance.

## Full-Stack Development

- Implemented a TypeScript monorepo with React, Vite, Express, Zod validation, Prisma ORM, SQLite persistence, and npm workspace scripts.
- Added clean API serialization so AI array/object fields are returned as typed values instead of raw JSON strings.

## AI Workflow Automation

- Implemented a deterministic mock-AI fallback so the MVP is fully demoable without paid API access.
- Added optional OpenAI SDK integration behind a service wrapper with structured JSON validation before saving analysis results.
