# DefectLens Demo Script

## 3-Minute Walkthrough

1. Open the dashboard. Point to total defects, Open, Critical, Closed, Analysis Coverage, root-cause mix, and high-risk modules.
2. Click a seeded defect. Show the original defect details, reproduction steps, affected fictional case IDs, and current status.
3. Click Generate AI Analysis or Regenerate. Explain that the app uses OpenAI when an API key is configured, otherwise it uses a deterministic mock fallback so the demo is always runnable.
4. Show Missing UAT Scenarios. Explain what was missing from validation and how these scenarios make the prevention action concrete.
5. Click Copy CAB Summary. Explain that this turns triage evidence into release-governance language that a CAB or delivery lead can use.
6. Close with: "This is how I think about defects - not as tickets, but as signals."
